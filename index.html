Each coordinate takes the next 2×2 pixels. Every pixel is copied into a 10×10 square, so the cell is a sharp 20×20 rectangle. A picture that is an exact multiple of the map, such as 2× or 3×, is shrunk by taking one pixel from each block. A strip or a GIF exports one 1920×1080 PNG per frame.
